📌 Slide 11: Eksplorasi Data (Pilihan Metode)

Setelah melihat fitur dan class, maka pilihan metode yang digunakan adalah:

Klasifikasi (Classification)

Alasan:

  1. Data target (output) berupa label kategorikal nominal (4 kelas penyakit yang bersifat diskrit), sehingga permasalahan ini secara alami masuk dalam domain klasifikasi multikelas (*multi-class classification*).
  2. Input sistem merupakan data citra tidak terstruktur (gambar) yang membutuhkan ekstraksi fitur spasial kompleks. Oleh karena itu, pendekatan klasifikasi menggunakan Deep Learning (Convolutional Neural Network) merupakan pilihan yang paling optimal dan akurat.

📌 Slide 12: Modelling

Algoritma apa yang ingin Anda gunakan untuk menghasilkan model:

Deep Learning: MobileNetV2 dengan Transfer Learning

  • Model menggunakan arsitektur MobileNetV2 sebagai feature extractor. Arsitektur ini dipilih karena memiliki parameter yang sangat efisien, sehingga komputasinya ringan dan optimal untuk di-deploy pada aplikasi web tanpa mengorbankan akurasi.
  • Menerapkan teknik Transfer Learning, memanfaatkan bobot pra-latih (pre-trained weights) dari jutaan gambar (ImageNet) untuk mengekstrak pola visual daun secara cepat dan akurat.
  • Classification Head kustom ditambahkan di akhir arsitektur dengan mengimplementasikan lapisan Dropout(0.5) untuk mencegah overfitting, dan diakhiri dengan lapisan Dense(4, Softmax) untuk menghasilkan probabilitas prediksi terhadap 4 kelas penyakit.

Model Evaluasi apa yang dipilih:

Evaluasi model berfokus pada dua metrik utama selama proses pelatihan:

  • Validation Accuracy: Mengukur persentase prediksi benar yang diujikan pada data validasi yang tidak digunakan dalam proses belajar.
  • Early Stopping: Model dievaluasi menggunakan mekanisme penghentian otomatis apabila Validation Loss (Categorical Crossentropy) tidak membaik selama 3 epoch berturut-turut, guna memastikan model tidak menghafal data (overfitting). Model terbaik disimpan secara otomatis (ModelCheckpoint).

Model AI berhasil diselesaikan dan di-deploy menjadi Aplikasi Web Lokal menggunakan framework Flask.
