# Agri Vision: Deteksi Penyakit Daun Padi

Proyek Capstone untuk mendeteksi penyakit pada daun padi menggunakan Deep Learning (MobileNetV2).

## Fitur Utama
- **Klasifikasi Penyakit**: Mendeteksi 4 kelas (Healthy, Brown Spot, Leaf Blast, Tungro).
- **Akurasi Tinggi**: Model mencapai akurasi validasi 95.36%.
- **Berbasis Web**: Antarmuka responsif menggunakan Flask dan Tailwind CSS.
- **Rekomendasi Organik**: Memberikan saran penanganan penyakit berbasis metode organik (mendukung SDG 2).

## Cara Menjalankan Aplikasi
1. Install dependensi: `pip install -r requirements.txt`
2. Jalankan server Flask: `python app.py`
3. Buka browser di `http://127.0.0.1:5000`
